# 02: 通用结构化资料进入现有检索链路

Type: task
Status: open
Labels: ready-for-human
Blocked by: None (can start immediately).

## What to build

资料维护者可从获准的 JATS/XML、Markdown 或纯文本导入资料，招募 Agent 能通过现有入口查到该资料并返回可核验原文引用。

## Acceptance criteria

- [ ] PLOS 导入不按 Ronaldo/Messi/PlayeRank 关键词特判；保留章节层级、段落 locator、作者归属、样本元数据和每个来源登记的许可范围。
- [ ] Markdown 保留标题、列表、段落等明确结构，纯文本保留段落；仍遵守每个来源的表格、图像、参考文献等排除政策。
- [ ] 对完整 E5 passage 输入（前缀、元数据、正文及特殊 token）做 tokenizer 预算校验，禁止静默截断。
- [ ] 相同规范化正文及有效元数据重复导入为 no-op；来源更新产生不可变版本，索引校验后再发布，失败时旧活动版本仍可查询。
- [ ] 能将至少六篇独立获准文章来源入库；来源数量不足时记录具体获取/准入阻塞，不用摘要或同文拆分虚增来源数。
- [ ] 通过招募 Agent 现有入口提出一个针对新导入资料的问题，结果引用能解析到稳定原文区间，正文和许可信息可追溯。
- [ ] 确定性测试使用获准结构夹具、临时 SQLite/LanceDB 和可控 embedding，不访问外网或下载模型。
