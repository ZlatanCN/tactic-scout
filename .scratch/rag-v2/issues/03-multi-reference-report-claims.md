# 03: 招募报告中的一条主张可以引用多处原文

Type: task
Status: resolved
Labels: ready-for-agent
Blocked by: 02: 通用结构化资料进入现有检索链路。

## What to build

招募报告可以综合两个或更多来源回答一个问题，并展示每个结论所依据的原文、作者归属和样本范围。

## Acceptance criteria

- [x] 报告主张保存引用数组，每个引用绑定不可变版本、章节、区间和文本 hash；多个引用可共同支持同一主张。
- [x] 正常回答能通过 JSON/SSE API 返回该结论及所有引用，来源摘要与论文原文、项目方法摘要区分清楚。
- [x] 一个必要引用失效、撤回或越权时，重新检查引用依赖并抑制该主张，不只删除引用标记。
- [x] 两份资料观点冲突时保留各自来源、样本范围及分歧，不生成未被来源支持的调和结论。
- [x] 外部测试验证引用精准区间、多来源同结论、撤回一个支撑来源后该结论被抑制，以及 JSON/SSE 结果一致。

## Answer

报告主张现在保存多条来源引用，每条引用绑定不可变 revision、章节 locator、区间与文本 hash；交付时重新校验，必要引用失效会抑制依赖主张。JSON/SSE transport 测试覆盖同一报告的引用投影、跨来源 claim 与失效引用处理；新增测试验证来源分歧会保留双方原文、归属与样本限制。自动验收标签仍为 AI 自动估计。
