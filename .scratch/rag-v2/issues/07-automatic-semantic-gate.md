# 07: 同网关模型自动评审与冻结验收门

Type: task
Status: open
Labels: ready-for-human
Blocked by: 04: 自动生成带原文区间的检索基准; 05: Agent 能针对资料缺口补查一次; 06: 本地专用重排模型与现有路径对照。

## What to build

维护者运行冻结题包后，系统能自动评估资料调查回答和排序方案，并生成可验收记录；评审分歧、评审失效、预算不足和执行中断都不会变成通过。

## Acceptance criteria

- [ ] 当前网关模型按隔离角色完成题目核验和回答评分，记录提示和模型标识，并说明同模型调用可能共享错误。
- [ ] 语义评审分别检查主张支持、必要事实覆盖和拒答范围；两个角色都支持才通过，都不支持为失败，分歧或不确定为未决。
- [ ] 受控正/负控制集检查正确引文、错误年份/数值、错引用和漏引用；正控制通过率至少 90%，负例无错误放行，否则标记 `judge_unreliable` 且不发布语义资格。
- [ ] 固定验收目标：支持率≥90%、必要事实宏平均覆盖≥85%、拒答处理≥90%；确定性权限/主体/引用/轮次违规为零，所有题型分别列分母。
- [ ] 汇总读者检索、提供参考原文的生成诊断和完整资料调查；不把 reader 直调结果说成应用端到端质量。
- [ ] 冻结题包、来源/索引/模型/提示签名、调用和 token manifest、所有失败与未决状态都完整匹配时才出验收记录；全流程预估超过 1,300 次网关调用时在派发前拒绝，不删题或对照以压低开销。
