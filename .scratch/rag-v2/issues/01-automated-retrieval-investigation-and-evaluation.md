# 新版 RAG：自动化资料调查与评测

Type: task
Status: open
Labels: ready-for-human
Blocked by: None

## Spec

[正式规格](../spec.md)。本任务覆盖现有招募 Agent 内的多来源资料综合、可追溯多引用、两轮/三十秒边界和无人逐题评审的自动验收。

## Scope

复用 LangGraph 和现有知识证据模块，通用化获准 JATS/Markdown/纯文本入库，建立 token-aware 切块和稳定引用；补充持久调查账本，支持一轮首查和一次证据缺口补查；产出无真人逐题评分、能保留未决项、限制自动模型调用、可以比较混合/本地排序/网关排序的评测流程，并让报告主张关联真实支撑区间。

## Acceptance

- JATS/Markdown/纯文本进入统一结构化资料，逐来源遵守许可、AI 目的地、主体与样本约束；E5 完整输入不超过模型窗口；相同正文/元数据重复导入幂等，撤回影响检索和引用。
- 一轮资料调查统一有持久状态、去重和调用记录，首轮不超过 3 个查询、最多一次补查/2 个查询、两轮共用 30 秒；外部网关调用 attempt 最多 4 次，未完成或结果未知的外呼不自动重发；最终引用核验和主张依赖关系有效。
- 检索对照可重跑全文、向量、RRF、网关重排和一个本地专用重排候选；查询—候选相关性有归属，排序对照使用完整有效候选，指标区分已标注 Recall、Hit、MRR 与原文事实组完整覆盖。
- 报告允许一条结论引用多个文档区间；来源归属、样本限制和事实差异保留；任何必要引用失效时不保留依赖它的完整结论。
- 题包来源为自动生成/程序核验/隔离同模型评审，记录来源版本、原文区间、事实组、答题可用范围、评审模型/提示版本和分组。题包至少 80 题/40 独立事实组/6 来源，不足时不生成“自动评测通过”。
- 任何数据准备或评测执行都在运行前给出完整调用清单；超过全流程 1,300 次上限不派发。失败、控制集不可靠、模型评分未决、预算超限或执行中断均不能建立验收记录。
- 主应用至少验证一个完整 JSON/SSE 案件内的跨资料综合、一次补查、部分/无答案状态、多引用投影、取消/恢复和失效引用抑制；reader 直调评测不能代替应用接入验收。
- 固定验证门槛为支持率至少 90%、必要事实宏平均覆盖至少 85%、拒答处理至少 90%、评审正确控制≥90%且错误控制无错误放行；确定性权限/主体/时间/引用违规为零。不得在看到冻结验证结果后降低阈值或移除题目。
- 规格内所有模型质量数字标为 AI 自动估计；只可报告小范围语料/题包的试点结果，不宣称真人复核、领域真值或未知来源泛化。

## Answer

RAG v2 实现、v5 冻结题包/控制题、开发集排序与检索消融，以及 validation candidate、fixed baseline、Oracle 都已运行。完整预算账本保守计为 1,257/1,300。最终 acceptance `data/knowledge/evaluation/runs/rag-v2-acceptance-v5-authorized-1300-reconciled.json` 为 `not_accepted`：候选低于基线，基线未达到支持/拒答门槛，5 个控制评分未决。所有质量分数均为 AI 自动估计，不是人类或领域真值。
