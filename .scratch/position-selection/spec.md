# 球场位置追问

Status: resolved
Labels: ready-for-agent

## Outcome
在招募对话中用真实俯视足球场多选位置，以结构化回答直接恢复 LangGraph；同一案件的搜索、位置证据、推荐和报告遵循同一组任一匹配的位置约束。

## Requirements
- 完整球场标线、草坪与真实纵深点位；十二个明确位置，不伪装成十一人阵型。大类快捷选择在场外。
- 仅位置类追问展示球场；问题编号与已选列表贯穿 HTTP、暂停恢复、浏览器草稿和请求幂等。
- 多选为任一位置符合，年龄/分钟/联赛等约束仍全部保留；同一球员不重复。
- 同族共享召回，跨族预算公平；每位置证据独立保存。数据缺口只形成线索。
- 确认即继续，错误重试保留选择，历史显示已确认位置；修改后重新调查，旧报告保留且标出条件。
- 320/390px、桌面、200% 缩放、键盘、焦点、非颜色状态提示和减少动效支持。
- 通过公开 HTTP/完整 LangGraph 与冻结 fixture 验证。对照自然语言重解析和结构化位置回答；提供列表/球场同条件交互对照。真人效率不凭自动化宣称。

## Design
现有字体与 shadcn 控件；足球场为唯一视觉主角。草坪低饱和深绿、白色标线、浅色位置标记、金黄色选择态。SVG 负责装饰球场，原生按钮负责交互。位置坐标属于视图，位置语义属于共享领域模块，传输模块不解释自然语言。

## Verification
待实现后记录命令、冻结样本与浏览器观察。真实手机触感与真人选择效率尚不能由桌面模拟证明。

实现与当前验证证据见 [verification.md](verification.md)。
