# 全位置能力相似公式与属性消融实验方案

Status: resolved
Labels: ready-for-agent

2026-10-25 执行完毕：[全位置实验报告](multi-position-report.md)。全局暂定公式为 RMSE；独立核验通过 120,960 条公式排名、10,080 条高潜名单和 10,320 条属性组消融结果。所有结论仍无独立球探相关性标签，不代表现实推荐质量。

## 1. 状态和结论边界

已有[实验报告](experiment-report.md)是 **STC 单位置**实验，已选 `rmse18` 作为该实验的暂定工程默认。它不能证明 RMSE 对其他位置、组合参考画像或高潜名单都更好，也不能作为全局公式直接上线。

本协议已在 14 个有候选的具体位置执行，选择一个跨位置共用的当前能力公式。`SW` 当前没有评分至少 15 的画像，不参加实验。实验没有真实球探相关性标签，RMSE 只能标为 `provisional`；PA 名单属于独立的确定性排序，不参与当前属性距离公式选型。

## 2. 冻结数据和位置特征

运行前已冻结 [position-feature-map v1](position-feature-map.json)，SHA256 为 `de7880a59a29e34fb28f93957af614552697bf125e40a95edc5b64703f408c88`。每个具体位置都有 raw 属性、解释组、选择理由、字段完整性和快照哈希。位置 feature list 不从 `role_scores` 逆向推导，因为其公式来源不可审计；也不让模型临场挑属性。

本地快照包含 52 项完整的 raw 属性。候选和每个参考人的位置资格都固定为该位置评分 `>=15`。位置分仅作过滤条件和结果说明，不参与相似度分数。

一个 query 可有一个或多个身份已确认的参考 FM profile。多参考 query 使用每个特征的等权算术平均画像；公式实验覆盖 2–3 个参考人的请求，不同参考不能跨开发/测试集合。对当前 CA gap 的诊断也使用参考集合的平均 CA，但 CA 不进入相似度公式。

## 3. 对比方法

每个具体位置比较相同的独立公式族：

1. MAE
2. RMSE
3. cosine distance
4. centered cosine / correlation distance
5. 基于训练集参数的标准化 RMSE
6. 使用训练集收缩协方差的 Mahalanobis distance
7. 预先锁定属性组权重的 weighted MAE

控制组使用候选 CA-only 排序和固定种子随机排序。它们用于发现“只看稳定性会误选”，不可能成为当前属性相似公式。固定特征数时等价排名不作为独立方法重复计数：L1/MAE、L2/RMSE，以及 Pearson 与逐向量中心化余弦。

为保持所有方法使用同一候选池，中心化相关距离遇到常量向量时预注册扩展规则：参考与候选都为常量向量时距离记为 0；恰有一方为常量时记为 1。该边界规则会有手算检查，相关距离仍因不保留整体水平而不具备全局默认资格。

每种公式都覆盖全部位置。属性消融使用预先冻结的位置属性组；保持候选资格和 query 不变，逐组移除，再分别报告 MAE 与开发阶段选出的全局候选公式。消融说明该组对本协议下的排序有什么影响，不证明它对现实球员质量有因果贡献。

## 4. 数据隔离和样本设计

- 以稳定 FM `unique_id` 在全库范围一次性分成拟合集、开发集、测试集；同一球员在不同位置的记录只能属于同一集合。
- 每个位置每个开发/测试集合各 120 个查询请求：单参考 60 个、双参考 30 个、三参考 30 个。
- 同一个位置、查询和过滤条件下，各公式使用相同候选 ID 集合；先处理完整候选集和硬条件，再排序和取 TopK。
- 同一个参考 FM ID 不会在同一开发/测试 split 的多个查询组或位置间重复使用；开发/测试也按全库 unique ID 隔离。
- 标准化均值/方差、协方差和公式超参数只从拟合集估计；开发集选择一个全局公式，冻结配置和选择哈希后，测试集只做确认。
- 主要 Top5/Top10 查询均排除全部参考 FM IDs，并执行 `position rating >= 15`。候选不足时返回实际数量，不能放宽条件。
- 数据版本、位置映射版本、环境、随机种子、分割清单、输入/输出校验和一并保存。

## 5. 场景和指标

每个位置、每种公式分别报告：

- 硬条件满足率、缺失值、重复身份、自身排除、有限分数、同分稳定性和候选池大小；正确性不合格的方法淘汰。
- 固定 `±1/±2` 原始属性扰动后的 Top5/Top10 Jaccard 与名次变化；同一请求的噪声由所有公式共享。
- 当前能力 CA gap、候选覆盖、每个位置的候选集中度、评分和 TopK 排序 p50/p95 延迟。
- 单参考与多参考分别报告；无年龄/CA 条件、明确的年龄上限、年龄上限加 CA 下限场景分开报告。
- 全局指标以每个具体位置等权的宏平均为主，同时给每个位置的完整结果和配对区间。大样本位置不能按人数支配全局赢家。

噪声稳健、低 CA gap、可用候选多或运行快，分别只是工程诊断，不是 relevance 标签。当前不计算 NDCG/Recall，也不使用模型评委或公式自己的 TopK 当作真实答案。公式选择报告不得写成“真实替代能力最好”。

### 预注册选择规则

在测试集解封前把数值门槛写入新实验配置。推荐沿用 STC 试验的工程起点：全位置宏平均 `±2` 扰动 Top5 Jaccard 相对 MAE 至少提高 0.02，配对 95% 区间下界大于 0；完整约束和非退化检查通过；算分与 Top10 排序 p95 小于 50 ms。CA gap 作为诊断报告，不参与排序或全局胜者分数。另预先登记单位置 J5 回退下限为 -0.10，防止宏平均掩盖严重退化。

开发集冻结选择 RMSE，测试集只确认该 challenger，没有根据测试集另挑赢家。测试宏平均 Top5 扰动 Jaccard 比 MAE 高 0.073，配对 95% 区间 [0.064, 0.083]；最低单位置增益 +0.050，p95 算分与 TopK 延迟 1.75 ms，均通过门槛。RMSE 与 zRMSE 都通过工程门槛，但 RMSE 宏平均更高。最终标为全局 `provisional`，并报告全部位置结果。

## 6. 高潜名单验收

高潜名单按候选 `PA` 降序，当前属性距离只在 PA 相同或并列时使用，之后以 FM ID 稳定排序；执行同一位置和用户明确给出的年龄、CA、PA 等硬条件。测试核验排序和条件满足率，并构造“低 CA、高 PA”的 fixture 确保候选能进入高潜名单。

这条列表不预测未来 CA，不将 `PA-CA` 解释成成长概率或保证增幅，也不与当前属性相似度合成分。未给 PA 下限时按 PA 排序；只说“年轻”未给年龄时由 Agent 追问年龄上限。

## 7. 复现与产物

- 已创建独立配置、入口、拟合参数、查询拆分、逐条排名、噪声结果、全局选择记录与验证器；STC-only 旧入口和 `selection.json` 未覆盖。
- 结果保存在 `.data/recommendation-experiments/20261025-multiposition-v2/`；摘要和可读报告分别在 `summary.json` 与 [multi-position-report.md](multi-position-report.md)。
- 独立验证器复算了 120,960 条公式排名、10,080 条高潜列表和 10,320 条特征组消融，全部通过。
- 实验没有调用网关、在线模型、Understat 或外部服务。

FM26 官方材料把当前能力与潜力能力作为不同考察维度，并允许分别设定位置、年龄范围和潜力要求；角色适配还取决于位置熟悉度和角色关键属性。因此这里把“位置级属性相似”和“高潜排序”分开，不声称已评估具体战术角色适配。
