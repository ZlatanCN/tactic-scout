# 改造候选报告、证据与比较

Status: open
Labels: ready-for-agent

## Goal

用清晰、有层次的推荐卡、上下文摘要、来源记录和比较表呈现现有报告，让用户先扫描结论与关键依据，再按需核对完整样本。

## Scope

- 适配 `RecommendationCard`、`ContextCards`、`InsightCards`、`DiffTable`、`RecordsTable` 与 `SelectionActions` 的合适模式。
- 默认显示候选身份、结论、关键证据、主要取舍、样本限制、缺失数据与不确定性。
- 完整指标定义、来源记录、赛事/赛季和样本信息按需展开，同时保证比较时容易找到。
- 保留候选身份组、背景记录与有证据候选的差异；仅使用现有真实数据和操作合同。
- 小屏中保持信息可读；宽表只在自身区域横向滚动。

## Acceptance Criteria

- 关键证据、样本风险和未知项不会因视觉简化而隐藏或被改写成负面结论。
- 用户可清晰识别选择候选与开始比较后的状态；现有选择边界和人数规则保持不变。
- 报告摘要与展开细节使用一致的来源、单位、比赛样本和指标口径。
- 空结果、背景记录和成功推荐等状态不会共用容易误解的视觉语义。

## Testing

- 扩展报告呈现和比较行为测试，验证数据对应关系、缺口和可操作状态。
- 浏览器检查报告默认层级、证据展开、比较布局、长内容和窄屏表格滚动。
