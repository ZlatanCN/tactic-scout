# 建立共享视觉系统与工作区外壳

Status: open
Labels: ready-for-agent

## Goal

为全站 Beautiful UI 改版建立统一的深色高对比设计变量、共享导航和工作区结构，并在主招募工作台中落地计划导航、对话/进度、报告/证据三区域布局。

## Scope

- 建立适用于全站的颜色、排版、间距、层级、焦点与动效规则，以 TactiScout 绿作为品牌识别色。
- 沿用现有 shadcn、Tailwind 和 Lucide 基础，适配 `SidebarNav` 模式而不引入付费图标依赖。
- 桌面端支持计划导航、对话与进度、报告与证据区域；报告区可收起或调整。
- 小屏使用紧凑导航和对话/报告标签，不保留缩小后的多列布局。
- 组件和变量必须便于后续主工作台、报告、盲评、裁决及录制运行展示复用。

## Acceptance Criteria

- 桌面主工作台显示计划导航、对话/进度、报告/证据三个有明确层级的区域；用户可收起或调整报告区域。
- 小屏用户可在对话与报告间切换，主操作和导航易于触达，页面不出现整页横向溢出。
- 色彩、焦点、状态和减少动态效果规则集中且能由后续页面复用。
- 导航语义、键盘操作和状态提示清晰；不新增业务能力或改变路由行为。
- 上游 MIT 组件代码保留必要许可信息；额外依赖逐项审核。

## Testing

- 覆盖共享导航与工作台布局的用户可见行为，不断言具体样式类名。
- 浏览器检查桌面和窄屏布局、区域收起/展开、键盘焦点和减少动态效果。
- Web 构建通过。
