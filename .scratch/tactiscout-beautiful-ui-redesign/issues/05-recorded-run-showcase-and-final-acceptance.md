# 改造运行展示并完成全站视觉验收

Status: open
Labels: ready-for-agent

## Goal

将统一视觉体系应用于录制运行展示，并检查所有用户可见页面在实际桌面与窄屏浏览器中的完整体验。

## Scope

- 适配 `Flowchart` 等适合静态过程讲解的模式，清楚说明内容是已完成 Harness 运行的脱敏静态摘要。
- 保留录制运行展示中实际发生的用户澄清、工具动作、报告事实和数据限制。
- 检查主工作台、匿名盲评、裁决和运行展示的一致性、响应式、键盘焦点、对比度和动效。
- 确认未误引入思维链、虚假工具状态、假进度或旧报告/新调查状态混淆。

## Acceptance Criteria

- 展示页面不会被误认为实时运行或逐字对话重放。
- 四类用户页面使用统一主题和控件语言，页面特定的语义与状态仍清楚。
- 桌面与窄屏无整页横向溢出；表格如需横滚仅在表格区域内进行。
- 键盘操作、减少动态效果和可读对比均通过浏览器手工检查。
- Web 构建成功，相关行为测试通过。

## Testing

- 运行录制运行展示、工作台、进度、报告和盲评相关的现有测试。
- 按 [feature spec](../spec.md) 中的浏览器检查范围逐页手工验收；不新增浏览器自动化框架。
