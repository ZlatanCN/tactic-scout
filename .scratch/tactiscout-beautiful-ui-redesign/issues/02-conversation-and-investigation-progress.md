# 改造对话输入与调查进度

Status: open
Labels: ready-for-agent

## Goal

将 Beautiful UI 的对话输入与加载/任务行模式适配到现有招募对话和真实调查进度，让提交、追问、等待、停止、恢复和失败状态更容易理解。

## Scope

- 适配 `ChatComposer` / `PromptBar` 的输入与提示布局，保持现有自由文本和结构化回答行为。
- 适配 `LoadingState` / `TaskRows` 的视觉表达，展示当前真实阶段、耗时和安全阶段事件。
- 保留正在执行时的防重复提交、等待回答、取消、未知结果恢复、失败与重试交互。
- 让正在调查但暂时没有新事件、等待用户回答和恢复同一轮等状态有清晰且真实的文案。
- 支持减少动态效果；不显示隐藏推理、工具名、token 流、百分比或 ETA。

## Acceptance Criteria

- 用户能辨认当前输入和可执行动作，不会因新样式误触发重复提交。
- 运行、等待回答、取消、取消完成、失败及恢复状态均与现有运行状态一致。
- 进度摘要只呈现实际图节点/安全进度事件产生的信息，不模拟工具调用或虚构活动。
- 键盘焦点、忙碌状态和辅助技术语义保持清楚。

## Testing

- 扩展现有对话面板与会话恢复测试，断言可见状态和操作，不绑定类名。
- 浏览器手测新建、执行、等待补答、取消和恢复场景。
