## Acceptance criteria

- [x] 无关别名 / 持久化旧聊天不再全量进入模型；本轮明确提及、已有 focus、有效条件及所需已解析引用得到保留。
- [x] 名称规范化沿用既有规则，不通过近似姓名、最近记录或摘要新建 / 合并身份。
- [x] 单一可续接目标继续原任务；多个目标仍 native interrupt，保留本轮 patch，不能为减小输入猜测目标。
- [x] 大量无关别名、同名歧义、代词和省略目标等完整图场景得到准确结果，原始 aliases / 四类快照和跨线程 Store 记录不变。
- [x] 仅必要结构化上下文本身也过大时，如实进入已有待处理边界，不静默删掉参与者或条件；可观测输入反映实际选择范围。
