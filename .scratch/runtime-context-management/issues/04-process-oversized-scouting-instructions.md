# 04: 自动分块处理单条超长球探指令

Status: open
Label: ready-for-agent
Blocked by: 03
Parent: [运行时上下文管理](../spec.md)

**What to build:** 第一条用户消息自身大于一次辅助请求预算时，系统自动有界分块、提取并合并任务 / 限制，形成带原文定位的 Compacted scouting instruction 后执行；实际条件矛盾时保留进度澄清。

## Acceptance criteria

- [ ] 每个源批次及合并调用都满足自身预算，明确跟踪已处理 / 剩余范围，不能将整份超限输入交给摘要器或无限递归压缩。
- [ ] 全部参与者、团队、参考 / 排除对象、否定、数值 / 单位、位置、赛事 / 赛季和跨块指代被核对；后文明确修正与真正矛盾分别处理。
- [ ] 每条原文定位 / hash 有效，引用材料不升级为指令；独立块结果不能未经合并校验直接执行，语义保真不以 JSON 合法性代替。
- [ ] 已完成块与消耗可恢复；额度耗尽时解释未理解完整，不给出整体比较 / 排名，原有成功快照不被覆盖。
- [ ] 经完整图完成首条超长输入的 lookup / 比较 / 推荐代表场景；续接型用例包含跨块条件和重复压缩，确认真实 source IDs 和限制未漂移。
