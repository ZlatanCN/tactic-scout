# 06: 多人比较分批解释并完整交付

Status: resolved
Label: ready-for-agent
Blocked by: 03
Parent: [运行时上下文管理](../spec.md)

**What to build:** 球探比较许多已确认球员时，全部参与者和可比范围可在预算内分批解释；局部处理不被说成全体比较，完整结果在解释未完成时仍可使用。

## Acceptance criteria

- [x] 从完整已验证比较结果生成带精确来源 / 字段 / 覆盖的证据批次；模型输入估算选择最大可容纳的参与者批次，规划与调用共用调用数和活动时间额度。
- [x] 全部确认参与者、赛事 / 赛季、局部 scope 人数、coversAllParticipants 和全体共同范围数量保持；无共同范围和局部记录不被扩大。
- [x] 各 provider 数据、null / omitted / unavailable / unqueried、身份关系及缺失值声明保持；不为缩减输入剔除参与者或生成整体强弱排名。
- [x] 完成解释前对照完整快照重验投影字段和记录引用，并核验批次回答提及各自参与者；额度或输入预算耗尽时完整展示已验证比较数据与来源，标明解释未完成。
- [x] Saved comparison 复用原结果，不重跑查询；原快照先提交及失败保留语义保持。
- [x] 完整图与 evidence collector 用多参与者 / 多范围场景验证分批、coverage 和确定性交付，区分模型所见与程序读取的记录。
