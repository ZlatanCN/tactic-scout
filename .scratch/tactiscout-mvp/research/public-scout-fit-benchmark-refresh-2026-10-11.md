# 公开足球球探适配排序基准复核

复核日期：2026-10-11。仅检查男性足球相关来源。研究目的是判断公开人类评分能否作为 TactiScout 的 query-specific 短名单排序金标准；没有下载数据集，也没有将比赛统计、游戏属性或转会结果转换为人工标签。

## 结论

本次复核仍未发现可直接用于 TactiScout nDCG 评测的公开基准。最接近的是 2026 年一项真实球探 rubric 研究：16 名男性职业青训球探对 23 名 U13 男球员进行现场评估，按七个维度分别评分当前表现和潜力。它可以帮助设计可观察的评分维度、显示评分分歧，但既没有具体球队招募需求，也没有针对职责的完整候选池和可复用 qrels。

PlayeRank 论文报告了三名职业球探对 202 名球员的 211 对比较；但作者公开的项目和可见数据记录呈现的是 PlayeRank 算法分数及相关表现数据，没有找到论文中的完整专家成对标签。用 PlayeRank 自己的输出评估另一个排序器会形成循环验证，因此不能把它写成独立的球探适配准确率。

所以，项目已有匿名双人盲评流程仍是正确的验证途径。对空标签模板应保留 `not_evaluable`；只有在固定招募需求、固定完整候选池、双人独立评分并完成匿名裁决后，才计算逐 query 的 nDCG@5。人类评审判断只能代表该次需求与候选池，不应包装成普适球探真值。

## 对产品评测与 UI 的建议

1. 继续冻结自然语言招募需求（含澄清答复）、候选池、数据快照和候选排序，再生成不显示系统身份、排序位置或模型理由的评审包。
2. 至少两位评审独立按项目的 0–3/`unknown` rubric 评分，未知不能变成 0；完成匿名裁决后才揭示答案键并计算逐 query nDCG@5。
3. 把原始评审分歧、评分覆盖、候选池覆盖和 nDCG 分开呈现。2026 年实地研究的结果表明，即使是经验丰富的球探，潜力评分的评审间一致性也比当前表现差；产品不应把单一“球探共识分”伪装成客观真值。
4. 可从公开研究借鉴评分维度和措辞，但要标注“rubric 参考”，不能把通用属性或研究样本移植成球员标签。
5. 在有多条真实 query 标签之前，只报告案例级的证据覆盖、工具链行为与人工评分样例，不宣称通用推荐准确率或转会成功预测能力。

## 来源与访问限制

- 最接近的现场研究全文可在 SAGE 阅读；其数据声明链接到 OSF。文章许可不能替代 OSF 文件许可，本次未下载文件或宣称数据可再分发。
- DataverseNL 公开 DOI 和大学研究门户可以确认问卷数据记录存在，但 Dataverse 页面对自动访问启用了挑战；本次不声称核验了具体文件格式或再利用条款。
- PlayeRank 的论文报告了专家比较验证，而公开代码仓库的 README 定义了角色感知算法输入/输出。此审计只确认已检查的公开仓库/数据记录未发现专家标签文件，并不证明其他私有或未索引存储绝不存在。
- 本复核不下载或加工任何球员数据库，不涉及女性足球，也不改变 issue 119 的“等待真实人工标签”状态。
