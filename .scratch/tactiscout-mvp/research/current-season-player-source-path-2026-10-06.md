# 当前赛季成年职业球员来源路径

核查日期：2026-10-06。只采用各来源所有者的官方 API、文档、仓库、条款或许可证。接口 smoke 只用于确认 HTTP 可访问性和返回结构；没有保存原始球员响应。本报告不把未验证的覆盖或许可写成已可用。

## 结论

**这轮没有发现一条能立即作为 TactiScout 当前球员池、又能合法公开展示、长期保存并交给本地 LLM/RAG 的完整来源。**更值得推进的方向分两条：

- **新增技术候选：PitchAPI。**官方文档称免费 key 可读 77 个联赛、2021 年以来数据；逐场球员统计与高级指标包括分钟、VAEP、推进传球/带球、成功过人、抢断和拦截，且 2026-09-30 仍有 API 更新。它没有球员赛季聚合接口，需按当前赛季比赛逐场聚合；文档未提供成人生日/当前注册名单端点。PyPI 的官方 SDK 页面明确提示数据权利由独立服务条款管理，但文档和申请 key 页面没有找到条款入口，也未找到公开的展示、留存或 LLM/RAG 许可。因此它是本轮最值得做技术 smoke 的新候选，**不是已准入来源**。[官方 API 文档](https://pitchapi.dev/) · [官方 key 说明](https://pitchapi.dev/get-api-key) · [官方 SDK 与独立条款提示](https://pypi.org/project/pitchapi/)
- **表现证据优先：ASA（American Soccer Analysis）2026 MLS API。**它是本轮唯一实测到无 key 返回当季球员 xG、xPass、Goals Added 指标的候选，指标深度最好；但只验证了 MLS，而且 ASA 没有公开说明数据可被 TactiScout 持久化、公开展示或交给 LLM/RAG。当前只适合作为许可核实对象，不应先做持久化集成。
- **有公开产品条款的候选：SportScore。**免费条款明确允许缓存、衍生产品和带署名的早期商业应用；但官方射手榜示例端点实测 404，替代响应也未验证赛季、完整性或成年身份，当前不能作为可用的球员发现源。
- **foot.io**覆盖目录和球员身份字段丰富，但 API 仍为 invite-only closed beta；free key 不是可自助领取。其许可门控明确排除了 xG、shot-level、转会，以及英超等 top-5 联赛的比赛事件和阵容。不能把目录中的 held/schema 字段当成 key 实际可读的当前数据。
- **OpenLigaDB**可无 key 读取当前 Bundesliga 射手榜，且 ODbL 明确允许复用并附带署名和 share-alike 条件；它只提供进球者与进球数，只能作为补充事实，不能建立候选池或能力评估。
- **football-data.org** 能提供部分当前球队名单，但球队/球员数据需要 API token；其免费无 token 路径不含 roster。需付费深度计划才能取 squad，字段主要是基本身份/比赛统计，无法补足战术指标；公开展示要署名，缓存和 LLM/RAG 范围没有明确说明。

## 候选池与补充证据需分开

- **候选池**至少要能给出可验证的当前俱乐部/赛事、年龄（成人筛选）和稳定球员身份。ASA 的 MLS roster JSON 有名单结构但到 2026-02-26 即停；SportScore 未验证当前赛季射手榜，样例个体档案无生日/位置；foot.io 有全球 player register 和 DOB/position，但免 key 路径不构成受支持 API，current-club/roster 关联与 completeness 未验证；OpenLigaDB 只返回进球者。这四项都不能直接宣称是完整的当前候选池。
- PitchAPI 可以从本赛季已出场球员构造同源名单与能力证据，但无法列出未上场注册球员或年龄；它扩展表现样本，不自动满足完整成人转会候选池定义。
- **表现证据**方面，ASA 2026 MLS 的 xG/xPass/g+ 是明显超出纯进球统计的指标，但使用权未知；SportScore 的已见字段偏通用赛季统计且当前赛季/来源稳定性未验证；foot.io 的 xG、xAG、shot-level 数据不通过许可门控，top-5 lineup/event 也缺失；OpenLigaDB 仅能确认进球数。
- 若把所有 2026 数据混到一起排序，会混淆来源覆盖和字段口径。应保留 provider、league/season、stat scope、检索日期与证据时间，并把没有年龄/名单证据的人标为未知，而非自动当作成人现役候选。

## 最值得推进的切片

**首选下一条技术切片：PitchAPI 单联赛、最多三场的无模型、无落盘 smoke。**其官方文档字段深度远优于 OpenLigaDB，可快速核对 2026/27 目标联赛是否真有 player analytics 数据、指标非空覆盖及 API 响应稳定性。此 smoke 仅在本机用户自行配置 API key 后执行；没有可审查的服务条款或权利答复前，不建 provider、不把数据送给 LLM/RAG、不持久化或公开显示。若 smoke 与权利门槛不过，关闭这条路线并继续用许可边界明确的历史 Wyscout 样本；OpenLigaDB 只保留为接受 ODbL share-alike 的进球上下文 sidecar 备选。

如果要求切片本身必须增加成人候选或超越普通 box-score 的表现证据，则本轮**不建议开始数据 provider 实现**：先向 ASA 书面确认上述展示/保存/LLM 权利及最新 roster release。SportScore 等文档射手榜路由修复并返回可审查的赛季/身份字段前不接入；foot.io 需取得 invite 并逐源确认；football-data.org 需新 token 和至少 €29/月深度计划，而且字段仍偏基础 roster/stat。
