## Objective

修复所有细分位置查询共用的召回与资格问题：不让粗粒度来源过滤静默筛空，也不把宽位置或相邻位置升级成目标角色候选。来源位置字段、覆盖范围、样本分钟和不确定状态必须可追溯；候选报告应把“未核实位置线索”与推荐名单分开。

## Acceptance

- [x] 全部 17 种产品位置的父类与中间类召回关系一致；13 种细分/中间角色均验证粗粒度记录可召回但不能直接通过目标位置资格，左右侧兄弟位置不互相冒充。
- [x] 来源能力边界明确：Understat 用自己的赛季位置记录；StatsBomb 保留球员实际出场位置与对应分钟；ASA 的 W 等粗标签按位置族召回但不升格为左右边锋；Sportmonks 保留原始位置名，未注明方向的 Full Back/Wing Back 只作为位置线索；FPL、Premier League、FBref、Wyscout 的宽位置只形成未核实线索；mosaic 不跨来源借用位置证据。
- [x] LangGraph 对可能提供细分位置的来源按位置族有界续页，遵守来源 `nextOffset`；粗粒度来源停止无意义扩页并报告线索，不因此追问用户放宽位置。
- [x] 候选资格、评估、推荐和比较只使用满足当前请求且有来源证据的位置记录；粗位置、待核实、未观察到和来源不可用状态不产生假候选。
- [x] 报告单独呈现位置未核实线索与原因，不纳入推荐排序或比较；旧版本地报告仍可读取。
- [x] 对同一冻结 fixture 比较严格筛选、位置族召回、位置族召回加来源证据门控，覆盖 13 种细分/中间角色；另以 LangGraph 整图验证粗位置只显示线索、多位置来源记录按对应角色证据入选。结果不外推为真实市场覆盖或引援质量。
- [x] 定向位置回归 113/113、API/Web 构建和 `git diff --check` 通过。全套测试 542 项中 540 项通过；余下两项因当前沙箱禁止绑定 loopback 地址而以 `listen EPERM` 失败，不是位置链路断言失败。

## Design notes

- “位置大类召回”只解决数据源位置字段过粗造成的漏召回，不意味着候选资格放宽。
- 对 LB/RB/LWB/RWB，可召回 FB 与 DEF 宽记录；对 LW/RW，可召回 WG 与 ATT 宽记录。左右侧具体角色保持互斥。DM/CM/AM 从 MID 召回，CB 从 DEF 召回，ST 从 ATT 召回。
- 原生位置标签只能证明来源在该范围记录过此位置，不等于战术职责或胜任能力。
- 当来源粒度不足时，应诚实报告位置线索与缺口；不要把用户能回答的问题转嫁给用户。

## Answer

检索与资格已拆成两个不同判断：查询某细分位置时按其位置族召回，避免粗目录先把潜在线索筛掉；进入候选资格、评估和推荐前，必须由该球员自己的来源记录证明目标位置。兄弟位置不会互相冒充。

位置证据按来源保留原始标签、范围和可得的角色分钟。Understat 使用当前赛季原生位置记录；StatsBomb 从阵容位置区间累计实际出场分钟，并保留同一球员的多个位置；ASA 的宽 `W` 标签能召回 winger 线索，但不证明 `LW`/`RW`；Sportmonks 未注明方向的 `Full Back`/`Wing Back` 能作为左右边后卫线索，其原始标签保留在报告证据中；SkillCorner 不再把边后卫/翼卫、边锋压扁成 DEF/ATT。FPL、Premier League、FBref、Wyscout 等只有大类标签时，报告显示为独立的“位置未核实”线索；不参与推荐排序或候选比较，也不因数据缺口追问用户放宽需求。其他来源只有其自身返回的明确位置证据才有资格，mosaic 不借用别的来源替某条记录补位置。

机制对照以相同的 13 种细分/中间角色粗粒度 fixture 逐一比较三臂：严格精确筛选会漏掉记录；位置族召回能找回线索；加入来源证据门后，宽位置仍不会成为目标角色候选。LangGraph 整图另覆盖粗位置线索与 StatsBomb 多位置分钟两条路径。该消融验证的是位置召回与资格边界，不是现实候选市场覆盖、球员胜任度或推荐排序质量。

位置专项测试 113/113、API 构建、Web 构建和 `git diff --check` 均通过。全套测试 542 项中 540 项通过；另外两项测试需要本机 loopback HTTP listener，在本执行沙箱中被 `listen EPERM` 阻止。未做 live provider 全量刷新或真实市场准确率评估。
