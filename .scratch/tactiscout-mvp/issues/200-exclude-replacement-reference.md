# 200 — 替代者任务排除参考球员本人

状态：resolved
标签：ready-for-agent

## 问题
“为拜仁寻找凯恩的替代者”返回 Harry Kane 本人。现有替代意图只用于追问与搜索约束，没有排除参考对象；中文名与来源英文名也未关联。

## 实现
独立 replacement-target 模块从明确替代语句提取参考姓名，精确匹配；提供凯恩的显式中英文别名组，不使用姓氏相似度推断身份。候选约束统一用于待评估集合、评估动作及报告投影。调整拒绝推荐反馈，避免把所有拒绝归咎于位置。

## 验证
TypeScript build 通过。replacement-target、candidate-search-intent 和 recruitment-conversation 三组共 61 项通过。整图回归在候选池加入 Harry Kane，并让 Planner 主动评估及推荐他，确认最终评估与名单均排除本人。

## 边界
其他跨语言姓名需要显式别名或后续身份解析；不声称自动翻译所有球员姓名。旧报告快照需要重新分析更新。数据覆盖不足仍可能得到空名单，不用参考球员填充。
