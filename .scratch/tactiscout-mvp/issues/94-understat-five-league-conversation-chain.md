# Connect Understat's current Big Five season pool through the LangGraph report

Type: task
Status: resolved
Labels: ready-for-agent
Blocked by: none

## Goal

接入一个用户明确选择的公开抓取数据源，覆盖当前赛季英超、西甲、德甲、意甲和法甲表现记录；验证它经过 TactiScout 数据仓库、LangGraph 多轮/分阶段工具调用、证据校验和最终报告的整条链路。

## Scope

- 沿用 `PlayerRepository`，默认数据源和用户现有 `.env` 不变。
- 五个联赛页串行读取；缓存、响应大小与请求时限有界；遇到 403/429 停止，不重试或绕行。
- 用户未指定联赛时，候选分页按联赛轮转，避免来源载入顺序导致某个联赛长期占据第一页。
- 只映射实时响应可见字段，保留 Understat 原生 player ID、league namespace、位置组、赛季、抓取时间、字段定义及分钟/场次样本；不按姓名跨联赛合并。
- 缺失字段保持不可用；年龄未知时拒绝年龄上限查询并清楚解释；不伪造年龄、球队 ID、身价、合同、伤病、预算或战术能力。
- 以来源特定证据送入现有 Planner/Reviewer 工作流；百分位仅在同联赛、同赛季和同位置组内比较。
- 用户此前授权对公开页面进行抓取原型。本授权只代表项目实施意图，不代表 Understat 授予许可；不得声称数据处理、留存或公开展示已获来源许可，也不得将原始响应写入仓库。

## Acceptance criteria

- [x] `understat` 是可显式选择的来源模式；默认配置和当前用户 `.env` 保持不变。
- [x] Fixture 测试覆盖五联赛映射、来源 ID 命名空间、复合位置、缺字段/零分钟/年龄未知、派生 xG per shot、联赛轮转分页、缓存、响应大小、重定向及 403/429 停止行为。
- [x] 玩家证据与数据范围 API/UI/Planner/Reviewer 一致显示联赛、赛季、来源字段、样本和已知能力缺口；年龄硬条件不会被静默放宽。
- [x] 真实来源读取仍能从五个当前赛季页面返回记录；不将 fixture 通过冒充 live 验收。
- [x] 本地 Qwen 跑通自然语言输入 → 方法/来源调查 → 候选搜索 → 表现评估 → Reviewer → 有据报告的 LangGraph 链路；本次需求无需澄清，追问与同案恢复另由既有对话/Harness 覆盖。Harness 检查来源字段、证据引用与报告限制。
- [x] API/Web 构建、指定测试、全量测试和 `git diff --check` 通过。

## Answer

已完成。Understat 显式模式从五个当前赛季页面实时读取 2,121 条球员赛季表现记录。随后将同一 Harness 场景以本地 Qwen 3.5 9B + LangGraph 串行独立运行三次，3/3 通过全部 29 项检查；每轮完成 10 次工具调用、46 条进度事件、评估 30 名候选并生成 2 条有证据依据的考察线索。候选分页轮转覆盖英超、西甲、德甲、意甲和法甲；创造机会与射门机会质量两项请求能力均在三轮中保持 30/30 候选有对应指标。耗时分别为 351.710、116.645 和 115.302 秒（p50 116.645 秒，p95 351.710 秒）。

验证范围：这是一次模型行为与证据链验收，不代表长期稳定性或球探排序准确率。Understat 接口是未文档化的公开页面 JSON 路由；来源对自动采集、缓存、模型处理和展示的许可，以及新鲜度 SLA，仍未核实。数据池只代表所读取赛季表现记录，不是完整注册阵容或转会市场；预算、合同、伤病、年龄筛选和球探报告等缺口均须继续明示。`understat` 需显式选择，不改变默认来源或用户 `.env`。

2026-10-08 复跑记录：Harness 摘要为 `runCount=3`、`passedRunCount=3`、`passRate=1`；三次都完成相同工具数和进度事件数。p95 仍有约 5.9 分钟的长尾，UI 进度反馈有必要保留。模型输出与耗时会波动；三次通过仅增加行为可重复性证据，不能外推长期可靠性。
