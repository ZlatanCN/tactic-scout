# Screen newly available open player-performance sources

Type: research
Status: resolved
Labels: ready-for-human
Blocked by: none

## Question

Is there a current-season player-performance source not already screened or integrated that adds meaningful role-relevant coverage to TactiScout and has a credible free/open access route for a reproducible local portfolio project?

## Scope

- Read the current source matrix and dated source-screening reports first; do not repeat previously rejected leads unless an official source materially changed.
- Research official APIs, datasets, documentation, terms/licences, and source freshness from primary sources.
- Compare at least two genuinely new routes, including candidate-pool coverage, role-relevant fields, current-season freshness, access limits/cost, automation, local retention, local model/RAG, and public portfolio display.
- Recommend one concrete GO, bounded smoke, permission request, or NO-GO. Distinguish verified facts from unknown rights/coverage.
- Do not make provider API requests, scrape pages, use credentials, or persist player rows during research.

## Acceptance criteria

- [x] A dated Markdown report records the candidate comparison and direct primary-source citations.
- [x] The recommendation identifies what can be integrated now and which permission/coverage gaps remain.
- [x] Existing screened candidates are not presented as new sources without updated official evidence.
- [x] No API calls, scraping, credentials, or player-level data are used.

## Answer

See [the dated source screen](../research/new-canadian-current-player-performance-routes-2026-10-10.md). CPL and NSL are newly identified Canadian current-season routes, but neither has verified machine-access terms, complete coverage/freshness guarantees, or permission for local retention, Ollama/RAG, and public display. Do not smoke, scrape, integrate, or persist player rows until the relevant rights holder confirms a supported feed/schema and the intended uses in writing. CPL is the first permission request for the current men's scouting scope; NSL is relevant only if women's competitions enter product scope.
