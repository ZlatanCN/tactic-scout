# 重构双路知识证据检索

Type: task
Status: open
Labels: ready-for-agent

## Spec

[正式规格](../spec.md)。主测试面为知识证据模块的检索/引用解析接口，现有招募 HTTP 回合只承担少量接入验证。

## Scope

交付方法资料与外部历史球员分析观点两路：本地 E5、原生全文/向量混合检索、现有聊天网关有界重排、SQLite 权威原文与版本、派生 LanceDB 索引、可解析引用、按需触发与共享预算。

## Acceptance

- 取得并核验真实获准的试点原文，保留来源类别、作者和历史样本，完成模块及报告资料投影的可执行验证。
- 新索引可以从权威资料重建，旧引用仍定位同版原文；撤回后新检索、缓存与恢复均执行当前来源策略。
- 同用户回合的所有检索、重试与恢复共享 15 秒额外等待，重排至多一次，外呼完成未知时不会自动重发，迟到结果不会更新调查。
- 重排失败仅使用独立验收通过的对应混合基线，否则明确不可用；不放松来源、主体、时间和证据要求。
- 正确区分未尝试、未覆盖、零命中、取得资料、超时/故障与失效；定性资料不填补量化指标缺口，不伪造当前候选。
- 提供 20–30 题人工复核材料并准确记录实际完成状态，提交确定性回归、构建与独立真实检索/网关评测结果，明确小样本限制。
