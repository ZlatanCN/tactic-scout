- [x] Produce local per-trial JSON and an inspectable Markdown baseline report with per-workflow completion, contradictions, unsupported additions, false execution claims, required-fact omissions, three-trial stability, each metric's denominator/coverage, and all inconclusive/error/unfinished work.

- [x] Present baseline evidence and the next threshold/freeze decision without inventing an aggregate accepted/not-accepted quality target. The later threshold choice and actual held-out run do not block this ticket's development-baseline delivery.
