# RAG 重构首版覆盖方法资料与球员定性观察

首版同时覆盖方法资料检索与球员定性观察检索，以满足方法解释和具体球员定性依据的双重需求；球员路线先取得真实、获准的外部报告或分析资料组成有限试点集，明确展示球员与资料覆盖范围，用户提供第一方观赛记录不作为依赖。首批接受研究者针对具名球员的历史比赛分析观点，保留作者、时间和样本范围，用于验证检索、引用及历史范围识别，不能作为现役引援效用已经得到验证的证明。两路先通过合计 20–30 个代表性问题进行人工复核，由项目准备问题、候选原文、引用和评分表，再由用户或复核者判断原文是否支持回答；这项小规模试点用于发现失败类型，不代表一般性效果已经得到证明。
