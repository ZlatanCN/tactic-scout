# 0013 — 球场确认传递任一匹配的位置集合

Status: accepted

位置类追问采用结构化问题与回答，问题编号绑定暂停中的案件。球场、文字对照和确认历史共享领域位置名称；前端不从问题文案猜测是否展示球场。确认后的完整位置集合直接恢复 LangGraph，模型不能重新解释、删减或改成全部兼任。普通文字追问与旧报告继续兼容。

集合内任一位置有来源证据即可通过位置条件，年龄、分钟、赛事等仍同时生效。来源读取使用合并查询与共享预算，每个目标位置分别保存证据；一个来源详情可核实多个位置。改变证据范围后旧评估失效。报告分别呈现目标位置、各位置覆盖与同一球员符合的位置，同一球员不重复展示。

这一选择会贯穿案件状态、请求幂等、位置核验和报告，后续改为全部兼任将改变候选语义，必须显式另建需求模式。首版不提供兼任开关。球场使用装饰 SVG 与原生交互按钮，不增加绘图或动画依赖。
