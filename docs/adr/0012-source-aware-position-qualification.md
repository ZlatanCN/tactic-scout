# Source-aware position qualification

Fine-position search uses a broader position family to avoid losing records from coarse source catalogs, while candidate eligibility remains tied to evidence from that player's own source record. Broad-only, pending, unobserved, and unavailable positions remain explicit leads rather than recommendations; source evidence cannot be borrowed across providers. This keeps retrieval recall separate from football-role claims and avoids asking users to loosen a request merely because a provider lacks detail.
